# DUNE-GLoBES-Simulation

This repository contains the simulation codes used in my MSc Physics thesis on neutrino oscillation studies for the Deep Underground Neutrino Experiment (DUNE) using the GLoBES framework.

## Project Overview

The objective of this work is to study the sensitivity of the DUNE experiment to neutrino oscillation parameters and related physics observables.

The analyses include:

- CP Violation (CPV) sensitivity
- Mass Hierarchy (MH) sensitivity
- Sensitivity studies of:
  - θ13
  - θ23
  - Δm²31
  - δCP
